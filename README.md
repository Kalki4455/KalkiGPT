# 🤖 KalkiGPT

KalkiGPT is an AI-powered chatbot built using Python, Streamlit, and Google's Gemini API. It provides conversational AI capabilities along with PDF document analysis and voice interaction features.

## 🚀 Live Demo

https://kalkigpt-ejc6sxyrkkw9igrquyxcb6.streamlit.app

## ✨ Features

* 🤖 AI Chatbot powered by Gemini API
* 📄 PDF Upload & Question Answering
* 💬 Conversational Chat Interface
* 🎤 Voice Input Support
* 🔊 Voice Response Support (Local Version)
* 💾 Chat History Storage
* 🧠 Context-Aware Conversations
* 🌐 Web-Based User Interface

## 🛠️ Tech Stack

* Python
* Streamlit
* Google Gemini API
* SQLite
* PyPDF
* SpeechRecognition
* Pyttsx3

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Kalki4455/KalkiGPT.git
cd KalkiGPT
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate environment:

```bash
venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Create a `.env` file:

```env
GEMINI_API_KEY=YOUR_API_KEY
```

Run the application:

```bash
streamlit run app.py
```
